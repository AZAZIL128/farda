# ایران فردا — نسخه آزمایشی ۳.۲

این بسته برای اجرای آزمایشی محلی آماده شده و سرویس بکاپ، MinIO و فضای ذخیره‌سازی بکاپ از آن حذف شده‌اند.

## اجزای پروژه
- Frontend: Next.js
- Backend: Django و Django REST Framework
- Database: PostgreSQL
- Redis و Celery: برای صف و وظایف پس‌زمینه‌ای که در کد پروژه تعریف شده‌اند
- Nginx: ورودی وب و پراکسی فرانت‌اند و بک‌اند
- Docker Compose: اجرای همه سرویس‌ها

## اجرا
1. فایل ZIP را طوری استخراج کنید که پوشه `iran-farda-social` در مسیر دلخواه ایجاد شود.
2. وارد پوشه شوید؛ فایل `.env` برای اجرای محلی داخل بسته قرار دارد.
3. اجرا کنید:

```bash
docker compose up --build -d
```

4. وضعیت سرویس‌ها:

```bash
docker compose ps
docker compose logs -f --tail=100
```

نشانی برنامه: http://localhost:8080

## توقف
```bash
docker compose down
```

## شروع کاملاً تازه و حذف داده‌های آزمایشی
این فرمان دیتابیس، رسانه‌های بارگذاری‌شده و داده‌های Redis را حذف می‌کند. فقط زمانی اجرا کنید که واقعاً می‌خواهید همه داده‌های محلی پاک شوند:

```bash
docker compose down -v --remove-orphans
```

## نکات
- این بسته هیچ سرویس یا زمان‌بندی بکاپ ندارد؛ با حذف volumeها داده‌ها قابل بازیابی نخواهند بود.
- فایل `.env` دارای رمزهای تولیدشده برای همین اجرای محلی است؛ آن را عمومی نکنید.
- برای انتشار روی اینترنت، رمزها و تنظیمات امنیتی باید بازبینی و تعویض شوند.
- این بسته بر پایه سورس v3.1 موجود تهیه شده است. حذف MinIO و سرویس بکاپ انجام شده؛ این کار به معنی تست کامل عملکرد همه قابلیت‌های برنامه نیست.
